## 后续取舍说明（2026-11-03）

- 用户指出原回复遗漏未采用建议的原因，并明确授权立即发送已确认的两段补充文案。
- [#23 补充回复](https://github.com/LYiHub/Card-master-browser-extension-public/issues/23#issuecomment-6600589554)：说明网站禁用右键与自定义菜单的事件处理方式相似、自动判断存在误判风险；本版选择网站自行处理右键并保留复制辅助，不另增右键开关，网站原有右键禁用保持原状。这是本轮方案取舍，未宣称曾实现自动识别后失败或证明无法实现。
- [#22 补充回复](https://github.com/LYiHub/Card-master-browser-extension-public/issues/22#issuecomment-6600591829)：说明依播放器全屏状态隐藏可在看影片时让出画面、退出后恢复入口，因此本版没有再加入整站网址排除名单。
- 两条均按已确认的繁体中文原稿发送，API 核验正文一致、没有重复发送，两个 Issue 继续保持 OPEN。本轮仅补充回复和记录，不改运行时代码。
