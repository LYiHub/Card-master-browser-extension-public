# 视频全屏入口与设置执行文档

日期：2026-11-03

## 目标与范围

- 提供默认开启的“全屏时自动隐藏浮动入口”设置，位于“设置 → 界面”。
- 仅针对播放器标准或 WebKit 全屏状态；开启时隐藏 Logo、倍速和媒体入口，退出后恢复原有显示配置。
- 关闭时保留入口原有显示行为，并通过手动 Popover 顶层显示，避免入口被原生播放器全屏层遮蔽。
- 沿用入口设置的保存、广播、同步及快照恢复机制；旧配置缺少字段时默认开启。
- 保留初始化所需的布局尺寸、原有入口位置、卡牌隐藏选择和快捷键行为。
- 修复公共弹窗与配套卡牌列宽依赖网站根字号的问题，保留窗口约束与小屏适配。

## 实施阶段

1. 扩展入口设置模型、字段校验、默认值和单字段更新。
2. 接入设置界面及轻量入口、React 入口的即时显示开关。
3. 实现播放器全屏观察、顶层显示、透明背景、点击穿透及退出/卸载清理。
4. 补齐旧数据、保存广播、同步恢复、全屏生命周期及尺寸规则的回归验证。
5. 更新默认扩展构建目录，交接浏览器效果验收。

- 默认 `extension-dist` 下的 Chromium、Firefox、Safari 构建及浏览器原新标签页变体。
- 本执行文档与代码验证、人工验收清单。

## 实现要点

- `autoHideInFullscreen` 默认 `true`；缺少或非法的本地字段使用默认值，更新消息要求布尔值。
- 两套入口共享全屏观察和隐藏样式，关闭开关后通过已有设置广播立即更新。
- 原生播放器全屏时将入口宿主提升到顶层；入口是否隐藏仍由设置控制。宿主及自身 backdrop 透明并保持点击穿透。
- 退出全屏、卸载和显示 API 失败时清理顶层状态，避免普通页面入口被遗留隐藏。
- 捕获监听的移除使用显式 `{ capture: true }`，覆盖 Node 22 与较新运行时的测试差异。
- 弹窗上限使用 `896px`，配套卡牌列使用 `128px/176px`，保持原先 16px 根字号下的几何基准，同时避免网站根字号造成额外缩放。
