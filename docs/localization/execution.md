# 简繁中文国际化调研执行文档

日期：2026-11-03

## 目标

结合浏览器扩展官方机制、成熟开源项目源码和本项目结构，选择适合卡牌大师的简体中文与繁体中文国际化方案。

## 范围

- 调研至少五个有实际产品代码的开源扩展，固定拉取版本，记录来源和关键实现。
- 比较词条格式、原生浏览器国际化、React 集成、自动与手动语言选择、回退、翻译校验及社区协作方式。
- 覆盖本项目的牌库、设置、新标签页、AI 输出、后台提示、第三方内置工具、构建和测试约束。
- 本轮只修改调研文档；不安装项目依赖，不修改功能代码，不发布 Issue 回复或 Release。
- 不操作页面或查看页面效果，依据官方文档和源码调研；未来界面效果由用户验收。

## 阶段与交付物

1. 核对工作区、适用规范、Goal 和当前实现。
2. 拉取参考项目并固定版本，查阅官方文档。
3. 形成项目对照和方案取舍，核对本项目接入边界。
4. 交付 `research.md`，包含证据链接、推荐架构、术语规范、实施步骤和验收清单。
5. 检查文档、排除临时源码及证据，将本轮文档在现有仓库 `main` 提交并推送。
